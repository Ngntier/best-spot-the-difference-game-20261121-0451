DOUBLE TAKE — a spot the difference game: two near-identical pictures side by side, seven differences hidden in each of three hand-drawn scenes (Harbor at Dawn, Forest Camp, Night Market). Click a difference in either picture to mark it on both, use hints when stuck, and beat the clock. Wrong clicks cost points; fast clears bank a time bonus.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Play with mouse or keyboard: click a difference, H for a hint, P to pause, M to mute, Space to start. `?shot=start|play|play2|end|over&seed=N` stages a screenshot scene instead of the loop. `main.ts` (Node 22, standard library only) copies `game/` and `screenshots/` to `/output` and writes `/output/dossier.json`.
